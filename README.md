# DOA-it (Decentralized Autonomous Organization Platform)

A decentralized autonomous organization (DAO) platform built with Next.js and blockchain technology. This platform allows users to create, vote on, and manage proposals using the Ethereum (Sepolia testnet) blockchain.

## Features

- Wallet authentication (MetaMask, Coinbase, Phantom support)
- Proposal creation with OpenAI GPT-4 integration
- Token-based voting system
- Proposal lifecycle management
- Community-focused governance

## Getting Started

1. Clone the repository
2. Install dependencies:
   ```bash
   npm install
   ```
3. Create an `.env.local` file based on `.env.local.example`
4. Obtain an OpenAI API key and add it to your `.env.local` file
5. Run the development server:
   ```bash
   npm run dev
   ```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
